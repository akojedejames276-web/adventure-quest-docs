# Assets and attribution

All world geometry, tile-label textures, snake scale textures, hero models, environment landmarks, animations, synthesized melodies and sound effects were authored procedurally for this project. No third-party character, model, texture, image or music pack was downloaded.

Three.js, React, Vite and qrcode.react are dependencies under their respective upstream licenses; package metadata and the lockfile identify exact installed versions. System font fallbacks are used; no external web font request is required. Hero/name labels and chat are treated as text.
